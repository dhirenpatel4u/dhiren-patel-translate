Developer API

Dhiren Translate API

A simple HTTP API for translating text between supported languages.

Endpoint

The translation API uses a GET request.

GET /api/?sl={source}&tl={target}&q={text}
Parameter Description Example
sl Source language code en
tl Target language code hi
q Text to translate Hello world

Example request

Translate "Hello world" from English to Hindi: 

GET /api/?sl=en&tl=hi&q=Hello%20world

JavaScript

const params = new URLSearchParams({
    sl: "en",
    tl: "hi",
    q: "Hello world"
});

const response = await fetch(
    "/api/?" + params.toString()
);

const data = await response.json();

console.log(data.result);

Python

import requests

response = requests.get(
    "https://your-domain.com/api/",
    params={
        "sl": "en",
        "tl": "hi",
        "q": "Hello world"
    }
)

data = response.json()

print(data["result"])

cURL

curl "https://your-domain.com/api/?sl=en&tl=hi&q=Hello%20world"

Response

A successful request returns JSON containing the translation result. 

{
    "response": "success",
    "sl": "en",
    "tl": "hi",
    "result": "नमस्ते दुनिया"
}

Using your own domain

If your website is:

https://example.com

Your API URL becomes:

https://example.com/api/

The frontend translator on this website automatically uses the same-origin /api/ endpoint.

Important

The API implementation is intentionally kept separate from this website frontend. You can continue using your existing Python API without changing its code.
