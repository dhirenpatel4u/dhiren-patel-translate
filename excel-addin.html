Macro-enabled Excel Add-in (.xlsm)

What is the Excel Add-in?

Dhiren Translate is a Microsoft Excel macro-enabled add-in that provides useful custom functions and tools for everyday Excel work.

It combines text formatting utilities, Indian number-to-words conversion, translation and custom SUMIF functions into one Excel solution.

Features

  • Number to Indian Words – Convert numbers into Indian Rupees and Paise using the n2t() function.
  • Indian Numbering System – Supports Thousand, Lakh and Crore.
  • Rupees and Paise – Converts decimal values into Paise.
  • Excel Translation – Translate text directly from Excel using the Dhiren Translate API.
  • Uppercase – Convert selected cells to UPPERCASE.
  • Lowercase – Convert selected cells to lowercase.
  • Proper Case – Convert selected text into Proper Case.
  • Trim Spaces – Remove unnecessary spaces from selected cells.
  • Add Space – Automatically add spaces between letters and numbers where required.
  • SUMIFD – SUMIF-style calculation with support for merged cells.
  • SUMIFSD – SUMIFS-style calculation with support for merged-cell criteria.
  • Help – Open the built-in Dhiren Translate Excel help window.

Number to Indian Rupees Words

The n2t() function converts a numeric value into words using the Indian numbering system. 

=n2t(1234567.89)

Example result:

Twelve Lakh Thirty Four Thousand Five Hundred Sixty Seven Rupees and Eighty Nine Paise

The function supports:

  • Thousand
  • Lakh
  • Crore
  • Rupees
  • Paise

Values above 999,999,999.99 are reported as Number is too Large.

Translate Excel Cells

The custom Translate() function connects Excel directly to the Dhiren Translate API. 

=Translate(A1,"en","hi")

The function accepts:

Parameter Description Example
strInput Text to translate A1
strFromSourceLanguage Source language code en
strToTargetLanguage Target language code hi

Example: 

=Translate("Hello World","en","hi")

Text Formatting Tools

The Add-in includes several VBA tools for quickly cleaning and formatting selected Excel cells.

Tool Function Shortcut
UpperCase Converts selected cells to UPPERCASE Ctrl + Shift + U
LowerCase Converts selected cells to lowercase Ctrl + Shift + L
ProperCase Converts selected cells to Proper Case Ctrl + Shift + P
TrimString Removes unnecessary spaces Ctrl + Shift + T
AddSpace Adds spaces between letters and numbers Ctrl + Shift + S
Help Opens the Add-in help window Ctrl + Shift + H

Custom Excel Functions

The Add-in also provides custom worksheet functions designed to work with merged cells.

SUMIFD

Performs a SUMIF-style calculation while using the first value of a merged cell area as the criteria value. 

=SUMIFD(A2:A20,"Sales",C2:C20)

SUMIFSD

Performs a SUMIFS-style calculation with support for one or two criteria ranges and merged cells. 

=SUMIFSD(C2:C20,A2:A20,"Sales",B2:B20,"January")

Example

Excel Formula Purpose Example Result
=n2t(12500) Number to Indian Rupees Twelve Thousand Five Hundred Rupees
=n2t(12500.50) Rupees and Paise ... Rupees and Fifty Paise
=Translate(A1,"en","hi") English to Hindi नमस्ते दुनिया
=SUMIFD(...) SUMIF with merged cells Calculated total

Translation API

The Translate() Excel function uses the same Dhiren Translate API as the website. 

GET https://dhiren-patel-translate.vercel.app/api/?sl=en&tl=hi&q=Hello%20world

This allows the Excel Add-in to use the existing translation backend without requiring a separate translation service.

Installation

Download the Excel Add-in file first:

↓ Download DhirenTranslate.xlsm

  1. Download DhirenTranslate.xlsm.
  2. Open Microsoft Excel.
  3. Go to File → Options → Add-ins.
  4. At the bottom of the Add-ins window, find Manage.
  5. Select Excel Add-ins and click Go.
  6. Click Browse or use the available option to select the downloaded DhirenTranslate.xlsm file.
  7. Select the file and click OK or Add.
  8. If Excel displays a security warning, enable macros/content only if you trust the downloaded file.
  9. The Dhiren Translate tools and functions are now available in Excel.

Quick Start

  1. Download and install the DhirenTranslate.xlsm Add-in.
  2. Open or create an Excel workbook.
  3. Use =n2t(number) to convert numbers into Indian Rupees words.
  4. Use =Translate(text,"en","hi") to translate text.
  5. Select cells and use the text-formatting tools such as UpperCase, LowerCase, ProperCase, TrimString and AddSpace.
  6. Use SUMIFD and SUMIFSD when working with merged-cell data.
  7. Use the Help option whenever you need assistance with the Add-in.

Requirements

  • Microsoft Excel with VBA/macro support.
  • Macros must be enabled for the Add-in.
  • Internet connection is required for the Translate() function.
  • The translation function requires access to the Dhiren Translate API.

Need help?

Use the built-in Excel Help option or check the Dhiren Translate API documentation for information about the translation service.
