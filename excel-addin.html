Translate directly from Excel

Use Dhiren Translate inside Microsoft Excel to translate cells without manually copying text into the website.

↓ Download Excel Add-in

What is the Excel Add-in?

The Dhiren Translate Excel Add-in provides a simple interface inside Excel for translating text using your existing Dhiren Translate API.

Your translation API remains the same. The Excel Add-in simply sends translation requests to:

/api/

Features

  • Translate text directly from Excel.
  • Select source and target languages.
  • Use the same Dhiren Translate API.
  • No changes to your existing Python API.
  • Works with Excel on supported Microsoft 365 installations.

Installation

  1. Download the DhirenTranslate.xml manifest using the download button above.
  2. Open Microsoft Excel.
  3. Open the Excel Add-ins / Office Add-ins management area.
  4. Select the option to upload or install an add-in from a manifest file if available in your Excel version.
  5. Select DhirenTranslate.xml.
  6. Install or add the Dhiren Translate add-in.
  7. Open the Dhiren Translate task pane from Excel.

How to use it

  1. Open your Excel workbook.
  2. Open the Dhiren Translate Add-in.
  3. Select the source language.
  4. Select the target language.
  5. Enter text or select a cell.
  6. Click Translate.
  7. The translated text can then be inserted into your workbook.

Example

Cell English Hindi
A1 Hello world नमस्ते दुनिया
A2 Good morning सुप्रभात
A3 How are you? आप कैसे हैं?

API connection

The add-in communicates with the same API used by the website: 

GET /api/?sl=en&tl=hi&q=Hello%20world

This means there is no second translation backend to maintain.
